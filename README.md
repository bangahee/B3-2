# B3-2 Mini Git

Python으로 구현한 CLI 기반 Mini Git 프로그램입니다.

이 프로젝트는 실제 파일 내용을 저장하는 Git 전체 기능을 구현하는 것이
아니라, 커밋 메타데이터와 브랜치, 그래프 탐색, 정렬, 역색인 검색을 직접
구현하여 Git의 핵심 자료구조와 알고리즘을 학습하는 것을 목표로 합니다.

---

## 1. 주요 기능

- 저장소 초기화
- 커밋 생성
- 브랜치 생성 및 전환
- 부모 커밋 우선 로그 출력
- 날짜 및 작성자 기준 로그 정렬
- 두 커밋 사이의 최단 경로 탐색
- 특정 커밋의 모든 조상 탐색
- 커밋 메시지 키워드 검색
- 작성자 검색
- CLI REPL 인터페이스

---

## 2. 실행 환경

- Python 3.10 이상
- 외부 라이브러리 사용 없음

---

## 3. 실행 방법

프로젝트 루트 디렉터리에서 다음 명령어를 실행합니다.

```bash
python3 main.py
